# incident.io

Open incident.io incidents and on-call pages from Alfred.

```
inc 186                → open INC-186 (INC-186 works too)
inc on                 → on-call schedules
inc                    → incidents, on-call schedules, escalations, alerts
```

| Page | Aliases |
| --- | --- |
| Incidents | `i`, `inc`, `incident`, `incidents` |
| On-call Schedules | `o`, `oncall`, `on-call`, `schedule`, `schedules` |
| Escalations | `e`, `esc`, `escalation`, `escalations` |
| Alerts | `a`, `alert`, `alerts` |

| Key | Action |
| --- | --- |
| `↩` | Open in browser |
| `⌘↩` | Copy URL |

Set your organization slug (the part after `app.incident.io/`) in Alfred Preferences → Workflows → incident.io →
Configure Workflow.
