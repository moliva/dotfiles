# Emoji Search

Fast emoji search for Alfred, with lots of synonyms.

```
;party    → 🎉
;lgtm     → 👍
;rokcet   → 🚀   (typos are ok)
;🎉       → reverse lookup: name and shortcodes
;         → your most used emojis
```

| Key | Action |
| --- | --- |
| `↩` | Copy emoji |
| `⌘↩` | Paste emoji into the frontmost app |
| `⌥↩` | Copy shortcode (e.g. `:tada:`) |

Keyword and default skin tone are set in Alfred Preferences → Workflows → Emoji Search → Configure Workflow.

## Adding your own synonyms

If an emoji doesn't show up for a word you'd use, add it to `synonyms.txt`. Each line is an emoji
(or its `:shortcode:`) followed by comma-separated words:

```
🥰 heart, hearts, in love, adore
🫠 melting, overwhelmed
:tada: yay, shipped
```

- Synonyms rank as high as the emoji's official name, so they bring it to or near the top.
- Changes apply on the next keystroke. No rebuild needed.
- Lines starting with `#` are comments.

Emojis you pick often also rank higher over time (usage is stored in Alfred's workflow data folder).

## How it works

- `emojis.tsv` is the search index: Unicode CLDR names and keywords, plus GitHub, Slack, Discord/JoyPixels
  and emojibase shortcodes, plus GitHub gemoji tags. Generated by `build_index.py` from
  [emojibase-data](https://github.com/milesj/emojibase) and [gemoji](https://github.com/github/gemoji).
- `emoji-search` is a compiled Swift binary (`search.swift`) that scores the index on every keystroke.
  Exact name or shortcode matches come first, then name prefixes, then keywords. If nothing matches,
  it falls back to typo-tolerant matching.

## Building

```sh
./build.sh          # compile emoji-search (universal binary, needs Xcode command line tools)
./build.sh --data   # also refresh emojis.tsv from the latest emoji data
```

The binary isn't committed. `scripts/symlink.sh` in the dotfiles repo builds it and symlinks this folder
into Alfred's workflows directory.
